# Publishing House Invoice Management System (PVP)

A robust Java desktop application developed for managing invoicing, client accounts, and financial documentation within a publishing house.

## Project Overview
This project was designed to automate and streamline the invoicing workflow for publishing businesses. It handles the complete lifecycle of invoices—from creation and item management to tracking payments and client databases.

## Key Features
* **Invoice Management:** Create, update, and manage invoices, items, and billing details.
* **Client & Partner Database:** Maintain records of publishing clients, authors, and business partners.
* **Graphical User Interface (GUI):** Clean and intuitive desktop interface built using Java Swing.
* **Database Integration:** Secure and reliable data persistence managed via JDBC and MySQL.

## Technologies Used
* **Language:** Java (OOP, JDBC)
* **GUI Framework:** Java Swing
* **Database:** MySQL, SQLyog
* **Version Control:** Git

## Architecture
* Built following multi-tier architectural patterns with a clear separation between the presentation layer, business logic, and database access.
